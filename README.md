# Dvnloader 🟣

تويك لتطبيق **تويتش** على الآيفون، يسوي نفس فكرة Dvnloader:

| البث | وش تقدر تسوي |
|---|---|
| 🔴 **لايف الحين** | تختار الجودة ← تحدد المدة (ساعات + دقايق) **أو** "سجّل لين ما يخلص البث" |
| 📼 **بث قديم** | تختار الجودة ← تحدد من أي دقيقة لأي دقيقة بالسلايدر **أو** "نزّل البث كامل" |

- يتخطى الإعلانات اللي تنحط وسط البث المباشر.
- الأجزاء المكتومة (muted) في البثوث القديمة ما تخرب التحميل.
- يوقف التسجيل بروحه إذا البث خلص.
- تقدر توقف التسجيل بنص البث وينحفظ اللي تسجّل.

## طريقة الاستخدام

1. افتح أي بث أو بث قديم في تويتش ← اضغط زر **المشاركة** ← اختار **Dvnloader**.
2. أو: **اضغط بإصبعين مطوّل** في أي مكان بالتطبيق ← حط الرابط أو اسم القناة.
3. لما يخلص ← **احفظ / شارك**، أو تلقاه في تطبيق الملفات ← على الآيفون ← Twitch ← Dvnloader.

> خل التطبيق مفتوح وقت التسجيل/التحميل (الشاشة ما تطفي بروحها وقتها).

## البناء (بدون ماك)

1. ارفع هالمجلد كريبو جديد على GitHub.
2. **Actions** ← **Build Dvnloader** ← **Run workflow**.
3. في خانة `ipa_url` حط رابط مباشر لـ IPA تويتش **مفكوك التشفير** (decrypted).
4. لما يخلص، نزّل الـ Artifact اسمه **Dvnloader**، وفيه:
   - `Twitch-Dvnloader.ipa`: هذا تثبته مثل أي IPA تثبته عادي.
   - `Dvnloader.dylib`: إذا تبي تحقنه بنفسك (Sideloadly ← Advanced ← Inject dylibs، أو Feather/ESign).

إذا تركت `ipa_url` فاضي يطلع لك الـ dylib بس.

## ملاحظات

- البثوث القديمة الحديثة غالباً تطلع **.mp4**. القديمة (H.264 TS) تطلع **.ts**، وتشتغل على VLC أو Infuse، وتقدر تحولها لـ mp4 على الكمبيوتر.
- البثوث اللي للمشتركين بس ما تتنزل.
- إذا تويتش غيّر شي في الـ API، يمكن يحتاج تحديث.
- استخدمه لتحميل البثوث لنفسك، واحترم حقوق أصحاب القنوات.
